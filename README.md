# Firewall Simulation Project
# Objective: 
- The project aims to develop a basic network firewall simulation using Python. This simulation is designed to demonstrate the foundational concepts of network security, such as IP and port-based traffic filtering.

# Languages Used: 
- Python, Bash scripting

# Key Features:
- IP Blocking: The simulation includes functionality to block network requests from specific IP addresses. This is essential for understanding how firewalls protect networks from unauthorized access.

- Port Blocking: Alongside IP filtering, the simulation can block traffic coming to or from specified ports, helping to prevent unwanted or harmful communications.

- Connection Handling: The firewall can accept or reject incoming network connections based on predefined rules, mimicking the behavior of real-world firewalls.

- Terminal-based Interaction: Users can interact with the firewall through a simple terminal interface, providing commands to start the firewall, and observe real-time logging of the firewall's decision-making process.
